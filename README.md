# PART TEST PAPERS

Four-level assignment papers (L1 easy · L2 lengthy · L3 tricky · L4 PYQ/JEE-pattern)
for the Sri Chaitanya PRAGYA G8 Achievers batch, built from the scraped question sets
in `source-pdfs/`.

```
01-Surds/            papers/  keys/  solutions/  src/
02-Logarithms/       papers/  keys/  solutions/  src/
03-Quadratic-Equations/
04-Sequences-and-Series/
source-pdfs/         the four scraped question sets
syllabus/            G8 Common Part Test-01 syllabus
tools/               audit harness for the independent re-solve pass
```

Every answer key in this repo has been derived independently of the printed source
key, checked twice numerically (floating point, then 60-digit decimal), re-checked
after the options were shuffled, and then re-solved from scratch by a separate agent
that had not seen the working.

See **CLAUDE.md** for the method, the syllabus constraints, and current status.
